Before you begin

Your workspace, encrypted

TabBridge saves open desktop tabs and live tab groups. It cannot preserve logins, cookies, forms, scroll position, media state, page memory, full history, or Chrome’s separate closed Saved Tab Groups collection.

  • Local-only mode stays in this browser and supports encrypted file transfer.
  • Optional Browser Sync uses Google or Mozilla infrastructure and is eventually consistent: Chrome syncs only with Chrome, and Firefox only with Firefox.
  • Chrome ↔ Firefox transfer uses an encrypted .tabbridge file.
  • Restores always open new windows and never close or replace existing tabs.
  • Your passphrase is never stored or recoverable. Losing it means losing access.
  • Desktop only. Standard mobile Chrome and Firefox Android sync are unsupported.

Settings & privacy

Device

Browser Sync

Opt-in sync sends encrypted records through your browser vendor’s sync service. It is not real-time, cannot confirm remote delivery, and never crosses between Chrome and Firefox.

Encryption

Forgotten passphrases cannot be recovered. Changing it re-encrypts every snapshot.

Exact privacy model

No developer-operated server, project account, telemetry, ads, or runtime network requests.

Local-only data stays in extension storage. Browser Sync is optional and uses Google or Mozilla infrastructure. Exported files are encrypted locally.

URLs can contain secrets. TabBridge encrypts payloads, but a compromised unlocked browser profile can access them. JavaScript cannot guarantee memory erasure.

Help & limitations

What restores

Normal-window separation, tab order, duplicate URLs, pinned state, active tabs, and—when supported—live group membership, title, color, and collapsed state.

What does not restore

Page memory, logins, cookies, form values, scroll or playback position, full navigation history, unsaved data, private tabs, privileged browser URLs, or closed Saved Tab Groups.

Cross-browser transfer

Export a snapshot with a dedicated passphrase, move the .tabbridge file, then import it in the other browser. The entire file is authenticated before anything is saved.
